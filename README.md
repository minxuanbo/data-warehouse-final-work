# 数字技术岗位需求与技能结构分析数仓

四人数据仓库课程项目。自主采集腾讯、网易官网招聘信息，围绕岗位方向、技能训练和门槛适配支持人才培训与就业指导规划。采用 **Kimball 维度建模的岗位日状态扩展星型**，通过 **ODS—DWD—DWS—ADS** 分层加工，以 Power BI 展示主题分析及原文证据。

## 当前进展与边界

2026-11-18 已重整主题、信息包、事实粒度与实际扩展星型，补岗位结构、技能、门槛主题接口和业务分析；修正源类别/标准类别命名及报表自动关系风险，统一设计与实现说明；随后补正腾讯中文经验规范化、正文学历提取及门槛证据。Windows 本机链路为 Python 3.12 → SQL Server 2025 → dbt → Power BI，SSMS 用于管理。

**当前仍为小批联调阶段。**两个固定批次各 100 个来源岗位、98 个核心岗位，技能关系分别 333/334 对。腾讯观察日为 2026-10-31，网易为 2026-11-01，均为 partial。技术验收通过不等于完整市场覆盖；当前不计算完整日趋势，不声称跨来源岗位已归并。100 岗人工技能复核包包含原参考40岗、新增60岗，仍待真实人工提交；连续完整采集在小批通过后推进。

2026-11-20 补第06页技能分子/正文分母/占比与多选并集说明，新增[样本训练决策案例](reports/analysis/小批技能训练决策案例.md)，准备自动主方向边界复核，修正当前交接材料。按[小批计划](docs/小批联调后续计划与四人分工.md)分工收口后，再进入扩量与连续观察。

Power BI 有七页：小批概览、技能与组合、岗位与证据、构建与质量、项目质量 KPI、岗位需求多维分析、快照岗位与证据。历史 CD 小批和日状态投影各自固定版本，不通过正文或事实明细互连。首次在新电脑使用，须按仓内说明关闭“加载后自动检测新关系”。

## 文件组织

`collectors/` 采集；`data/` 经 Git 交付的正式批次；`etl/skills/` 词典/提取；`warehouse/` 与 `sql/` 持久接入和模型；`dbt/` 分层转换、测试、文档；`dashboards/powerbi/` 报表定义；`docs/design/` 七章正文与三张主图；`docs/reference/` 字典；`docs/verification/` 当前整改结论；`reports/` 真实分析和带日期证据；`scripts/` 运行入口；`tests/` 离线回归；`research/` 历史试采。

`.local/`、Python 环境、BI 缓存和数据库文件不提交；**采集数据的 data/ 继续通过 Git 管理**。根目录保留老师的要求、答辩模板及按当前进度填写的课程报告。带日期的旧报告保留其历史范围，组员按上方当前入口操作。
