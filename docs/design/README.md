# 岗位需求数仓设计与实现

> 当前运行数据已切换到腾讯、网易、小米、京东四来源1579岗/1556核心岗；版本与验收见[四来源扩量联调](../verification/四来源扩量联调.md)。本章涉及200岗的数量为历史小批设计验证；正式报告按用户要求暂缓更新。

本项目将腾讯、网易、小米、京东的公开招聘记录整理为可回溯的岗位需求分析数据，服务人才培训与就业指导的规划决策。**主分析模型为岗位日状态扩展星型；ODS—DWD—DWS—ADS 组织加工过程，DIM 提供分析属性，AUDIT 保存运行与发布证据。**

设计与答辩版核查：2026-11-20。先确定主题、业务过程、粒度、维度与事实，再落实实现。当前来源岗位身份按官网区分，不声称完成跨来源实体归并。正式报告及答辩手册按用户要求暂停更新，现有文件仅为旧小批底稿；当前先以四来源数仓和技术验收为准。
