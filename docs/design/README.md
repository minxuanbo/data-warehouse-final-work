## 本版统一决策

- 中国大陆工作地点；不限定单一城市。腾讯、网易为主来源，额外企业先验证后纳入，当前不假定它们可采。
- 开发、测试、数据开发/分析、算法/AI、运维/安全为核心岗位类别；社招、校招、实习分别展示；非技术和综合招聘简章不进入核心岗位指标。
- 每日采集，首轮观察目标为连续 14 天；不追造历史。若实际周期不足，仅披露已观察日期。
- 独立区分来源发布记录、归并岗位、采集观察、每日岗位快照。薪资为可选指标。
- 已确定 Windows 本机部署：Python 3.12 + HTTPX/Pydantic、SQL Server 2025 + SSMS、dbt Core + dbt-sqlserver、Power BI Desktop；任务计划程序调度。数据库本机只读连接已验证，dbt 和报表端到端链路仍待验证；不要求 Docker、Prefect 或 SSIS。
- 当前只交付设计，不创建运行数据库、不启动正式扩量采集，也不把候选工具写成已部署。

## 设计审核与变更

A/B 审核字段、来源和采集成本；C 审核键、粒度、发布事务；D 审核业务问题、技能规则和分母。设计基线及第 2 章引用的采集契约现已冻结为 v1.0，按[提交入口](../../data/README.md)交付小批数据。机器资源、额外来源、组员姓名和实际开始日期仍需登记，不影响目前先完成模型设计。

新增来源、岗位分类、归并规则、技能词典或指标变更必须记录版本；范围变化时不可直接对比前后“新增岗位”。代码、设计版本、规则版本、数据批次共同构成一个可复现分析版本。
