# 新版技能提取与交叉抽检验证

2026-11-01。词典 `skills-dict-0.2.0`（140 项），规则 `skills-rules-0.3.0`，正文哈希 `skills-body-1.1`。腾讯包含职责、任职要求和附加要求；网易第三字段为 null。

## 抽检与冻结方法

两个来源各审读 20 岗，共 40 岗。腾讯覆盖深圳、北京、广州、上海、杭州和游戏、后台、数据、算法、编译、全栈等方向；网易覆盖杭州、广州、上海、北京及引擎、全栈、音视频、数据、运维安全、测试、算法和人工标注边界。

交叉抽检逐项对照原始响应、采集统一字段、腾讯增强字段及提取证据位置。全批另做原始字段回查：腾讯 100 个原始详情的 Responsibility/Requirement/ImportantItem，网易按 raw_refs 使用完整列表正文，有详情的使用已存详情。没有重新请求全部网易详情。

每来源开发 10 岗、最终留出 10 岗，ID 不重叠。腾讯本轮留出还排除了全部历史审读岗位；旧最终样本转为回归。开发集用于修正规则和词典，参考与提取器/词典文件哈希冻结后才运行最终计分；最终差错保留，本版没有据此改规则。开发集的备选标签复核记录在参考的 development_adjudications。

参考包含 323 个逐字证据锚点，其中 313 个在词典内，10 个是词典外命名技术示例。强度分数检查这些锚点，不是对所有证据出现位置的穷尽标注。

## 复现与证据

运行命令见[分析入口](README.md)。每来源的 `cross_review_20.csv` 有岗位、方向、原文件/哈希、字段比较、冲突与备注；`review_labels.csv` 有参考证据及字符位置，`validation_errors.jsonl` 保存实际差错。

已通过 23 项单元测试，包括第三字段、CRLF/Unicode 偏移、正文哈希变化、否定/优先/备选、年限误判、核心/城市/经验筛选、增强文件篡改和身份错配拒绝。另已逐条回查 1,067 条证据的字段位置、原始响应哈希和三字段正文哈希；独立重算 437 种城市/经验/类别筛选组合；两来源各 12 个输出文件重跑后逐字节一致。140 项词典的正文依据及新增词的开发/历史样本来源均已核实。

实际命令还验证了下载交接目录输入、腾讯城市冲突筛选（分母 9）和网易单独计分。离线看板的 JavaScript 通过 Node VM 执行检查：默认核心分母 98、城市/经验冲突、空结果、技能下钻和证据弹窗均符合预期；本轮未做浏览器视觉验收。
