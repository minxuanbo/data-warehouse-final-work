# 新版指标口径与 C/D 对账

## 样本与分母

按 `(source,source_job_id,batch_id)` 唯一。两个来源各为单个 partial 小批，分别统计；不把它们当全量市场，也不生成趋势、新增或下架结论。

腾讯使用 C 已确认的 is_core：100 岗保留，核心 98，排除售前 FDE 2072248701686034432 和趋势研究 2082723395740549120。网易全 100 岗完成范围筛查，建议将人工标注 78482、79489 作为扩展，核心暂 98；`scope_status=proposed_pending_C`，不能表述为 C 已批准。

P 是当前来源、批次、is_core=true，且通过城市、经验和源类别筛选的岗位集合；T 是 P 中三个正文字段至少一个非空的集合。当前两批默认均为 |P|=|T|=98。未匹配任何词典技能的有正文岗位仍进入分母，腾讯 15 岗、网易 18 岗。

| 指标 | 分子 / 粒度 | 分母与未知处理 |
| --- | --- | --- |
| 核心岗位数、正文覆盖 | P 数量、T 数量 | 覆盖率为 |T|/|P|；空分母 null |
| 类别、学历、招聘类型 | 来源原值的不同岗位数 | |P|；缺失“未知”，不限单列；招聘代码不擅自译码 |
| 城市 | 当前城市组中的不同岗位数 | |P|；城市冲突单列，确认多工作地各计一次，合计可超过 P |
| 经验 | 冲突组或来源经验原值的岗位数 | |P|；未知与不限分别保留 |
| 技能出现占比 | T 中具有该技能有效证据的不同岗位数 | |T|；先筛核心、城市、经验、类别，再去重计数 |
| 技能组合 | 同时含两项有效技能的不同岗位数 | |T|；每岗技能集合生成无序对，不统计证据条数 |

有效证据要求 `eligible_for_metric=true`；当前规则排除否定、备选和不确定语境。技能下钻只筛明细，不改变指标分母。筛选后必须重新求分子/分母，不能平均各组比例；零分母显示“—”。

腾讯城市按 C 的 location_conflict/confirmed_locations 处理，冲突 9 岗归“冲突待确认”，2059160518509379584 同时归北京、深圳；经验冲突 3 岗同样单列。网易仅去掉地点的“市”后缀做展示分组，78590 城市冲突单列；13 条“结构化不限、首行有年限”提示暂归经验冲突待确认。后一规则只覆盖这类明确表达，不声称完成全部年限语义解析。

网易学历 71196 的本科/硕士差异单独记录；`education_raw` 分布保持来源本科，不冒充已裁定的规范化学历。没有薪资就不生成薪资图。

## C 接入

交给 C：共用 `dictionary.json`，每来源的 `skill_evidence.jsonl`、`input_provenance.json`、`reconciliation.json`、`data_issues.jsonl`；网易另附 `scope_review.csv` 确认范围。抽检与验证记录从本 PR 读取，不重复打包原始数据。

C 按自然键定位已选输入版本，再映射 version_key；不能用标题或数字 ID 猜版本。正文哈希升级为三字段、skills-body-1.1，网易第三项固定 null；证据字段与位置保持独立。保留词典/规则/正文哈希版本、原文、强度、语境和来源引用。CSV 仅便于查看，机器接入读 JSONL。

已读取 `feature/warehouse` 的 ADS 定义：`ads.cd_overview`、`ads.cd_job_detail`、`ads.cd_skill_evidence`、`ads.cd_skill_demand`、`ads.cd_skill_pair`、`ads.cd_city`、`ads.cd_experience`；网易已有 `ads.dual_job_detail/dual_city/dual_education`。本轮未执行数据库查询。

当前 `cd_job_detail.sql` 和 `cd_skill_demand.sql` 的 skill_text_scope 仍写两字段，仓内现有 build_id=1 也是旧规则结果。C 接新版时需同步三字段范围与新提取版本，创建或选择新构建，再按 build_id/source/batch_id 对账，不能混查两个版本。网易范围与经验提示先确认，再确定正式核心分母。

依次核对：输入文件与身份集合 → 三字段哈希 → 全部/核心证据和有效岗位×技能 → 每项技能、组合和分母 → 城市/经验冲突及双工作地 → 证据下钻。C 负责接入、分层 ETL 与构建发布；D 当前只交程序和派生结果。

## 离线草图
