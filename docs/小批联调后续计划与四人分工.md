## 小批联调的通过条件

1. 固定两批从文件到ODS、事实/维度/桥、主题指标可复现，重跑不重复入账；两源各100/98，技能关系333/334保持可解释。
2. 第06页选Python显示54/196=27.6%；Python与C++多选按岗位并集计数；分母不随技能缩小，地区和门槛改变后分子分母一起按人群重算；无匹配技能为0，零正文分母为BLANK。
3. 至少另一成员按[仓内运行说明](../warehouse/README.md)复现，开发者本机成功不替代接手验收。
4. 分类边界样例、网易门槛冲突都有明确的待办或带证据裁定。未解决的语义问题继续标记，不要求为通过联调强行消除全部未知。
5. 100岗技能复核有真实提交才形成分数；未完成时如实保留pending。页面/SQL通过与人工准确率分开记录。
6. 一个样本决策案例能从人群、门槛、技能/组合计数回到岗位原文。结论保留来源、日期、分母和partial限制。
