# 广东开发方向的技能训练样本案例

生成日期：2026-11-20；参考 sample 发布 `8`。当前为小批联调。
本案例只读查询数据库 `recruitment_dw_dev_cd_v1` 的固定已发布星型。

规划情境：培训组织准备为已有开发基础的本科背景学员选择一个训练模块。先查看广东开发方向中明确标为“本科”的岗位线索，再比较技能与组合覆盖；这是设计使用情境，没有虚构企业访谈或培训效果。

## 先确定分析人群

两个不同观察日的部分样本中，广东且自动主方向为“开发”的核心岗位共 60 个；学历分组为：未注明17岗、本科31岗、硕士4岗、不限4岗、冲突待确认4岗。
其中明确“本科”组 31 岗，有效正文分母 31；零技能命中 3 岗仍保留分母。
“本科”组仅用来限定披露一致的观察集合，不代表本科毕业生均符合岗位条件；不限、未注明、硕士及冲突组分别保留，也不能据此判断不适配。

## 据此选择训练内容

本组可先把 C++ 作为训练模块的候选，因其覆盖 18/31 岗；再以 C++ + Unity 的共现任务设计组合练习，组合覆盖 7/31 岗。候选需结合讲师能力、学员基础和逐岗要求再决定，不将最高频直接等同于必须开设的课程。
先让学员完成基础能力诊断，再选一项覆盖较多的技能进行小项目，组合练习用于已有相应基础的学员。必需、优先和明确提及均可能进入这里的覆盖指标，实施前应回查要求强度，不能把所有命中都解释成硬性门槛。
经验组为：3年以上6岗、冲突待确认2岗、5年以上2岗、1年以上5岗、2年以上3岗、3-5年6岗、5-10年1岗、不限6岗。不把“1年以上”等开放区间当成“仅需1年”，也不据此自动判定应届生适配。

## 在 Power BI 中复核

第06页选择学历“本科”，在“技能训练线索”表展开“开发→广东”；查看技能岗位数、正文分母与占比。选单项技能看分子变化，多选取任一命中；本案例的技能组合取同时命中，不能拿多选并集代替。右键主方向钻取第07页，核对岗位与原文。
第06页的其他地区和方向仍保留作对照，不把某个展开行误当成全页筛选。组合值由固定发布的岗位技能集合独立计算。
