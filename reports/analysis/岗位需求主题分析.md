## 从分析到训练安排

情境：为已有开发基础的本科背景学员选择训练模块。以“开发×本科”为预设筛选，选正文样本最多的浙江作为演示组；这用于展示方法，不表示该地区市场需求排名。分母117岗，来源组成{'netease': 116, 'tencent': 1}，零技能命中20岗仍在分母。

| 技能或组合 | 覆盖 / 正文分母 | 占比 |
| --- | --- | --- |
| C++ | 46/117 | 39.3% |
| Python | 30/117 | 25.6% |
| Unreal Engine | 27/117 | 23.1% |
| Unity | 23/117 | 19.7% |
| Java | 18/117 | 15.4% |
| C++ + Python 同时命中 | 20/117 | 17.1% |
| C++ + Unreal Engine 同时命中 | 16/117 | 13.7% |
| Unity + Unreal Engine 同时命中 | 16/117 | 13.7% |

可先将C++列为训练候选（46/117），再结合已有基础和组合共现设计练习。实施前须逐岗核对经验、要求强度和原文，未注明或不限不能简单认定适配；不承诺课程就业效果。

## B04 变化与验证

当前没有相邻完整四来源日基线，新增观察及内容变化为NULL。没有把旧100岗样本、网络续采或网页更新时间补成趋势。B01—B03的样本分析可以演示，B04只有真实数据条件成立才解释。

结构人口、门槛人口、技能分子和分母已与日状态明细及去重技能集合独立对账。查询固定release_id；更改规则形成新发布，旧原始观察和历史发布保留。AI辅助审计和程序回放不冒充人工盲审准确率。
