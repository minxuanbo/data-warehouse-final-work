# netease 采集程序 · 负责人 B

本目录用于提交此来源的采集代码。尚未实现采集器；已有可行性代码在 research/recruitment，不能直接视为正式契约通过。

数据放 `data/netease/<batch_id>/`，不放在代码目录。阅读[提交规范](../../data/README.md)和[来源/字段约定](../../docs/小组项目说明与采集交付规范.md)。

提交采集器时补齐以下内容：

1. Python 版本、依赖文件和安装命令。
2. 从仓库根目录运行的命令、输入参数、输出批次目录及退出码。
3. 官网/接口、发现方式、分页和详情策略、访问规则及已知限制。
4. 每个输出字段对应哪个原字段；类型转换、缺失与冲突策略。
5. 请求间隔、重试上限、断点或重跑规则及日志位置。
